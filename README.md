# Kurage 広告表現チェック（khyogen）

ホームページのURLを入れると、サイトを巡回して業種を判定し、「No.1」「地域最安」「〇〇円〜」「見積無料」「設立より前からの実績」などの表現を、景品表示法・特定商取引法・業種ごとの許可の決まりに照らして、**確かめたほうがよい箇所を根拠つきで一覧にする** PHP の一式です。

デモ: https://proto.exbridge.jp/khyogen/ （デモ版は点数と分類ごとの件数だけ）

- 判定はすべて規則で行い、AIは使いません。同じサイトなら、いつ診断しても同じ結果になります。
- 「違反です」とは言いません。出すのは点検の結果と、根拠の条文・ガイドラインまでです。法的な判断は弁護士・所管の行政機関の仕事です。
- PHP 8.0 以上・curl 拡張。データベース・Composer・npm は不要。レンタルサーバーに置けば動きます。

## 置き方

1. `public/` の中身をサーバーに置く（`khy_data/` と `khyogen_rules/` の `.htaccess` で、結果と決まりは外から読めない）
2. `khyogen_config.php.example` を `khyogen_config.php` にコピーして、必要なら設定を変える
3. `khyogen.php` を開いて、URLを入れる

## 決まり（khyogen_rules/）

- `common.json` … 全業種共通（No.1・最上級、言い切り、〇〇円〜、無料の条件、二重価格、評価の数字、特定商取引法の表記、事業者の表示）
- `seikatsu.json` … 生活関連サービス（水道修理・害虫駆除・鍵・リフォーム・不用品回収）：一般廃棄物の許可、古物商、水道局指定の自治体、建設業の許可
- `haken.json` … 人材派遣・職業紹介：派遣と紹介の許可番号、労働者派遣法・職業安定法で公開が求められている情報（マージン率・労使協定・教育訓練／就職者数・6か月以内の離職者数・手数料・返戻金）、求人の性別と年齢の書き方、派遣先の面接、「高収入」の金額
- 設立・創業より前の実績の照合は、計算が要るので `khyogen_engine.php` の `khy_check_years`

業種を足すときは、`khyogen_rules/<業種>.json` を足すだけです（プログラムは触りません）。規則の型は `khyogen_engine.php` の冒頭にあります。

## 検査

```
php scripts/check.php
```

ネットにつながずに、見本のHTMLで「拾うべきものを拾い、拾ってはいけないものを拾わない」かを確かめます（実サイトで出た誤検知も見本に入れてあります）。
